# L'Ondographe •°
Instrument graphique génératif des Sourciers du vivant.

## Démarrer

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

Fonctions : accords d'emojis, six propositions SVG, sculpture tactile, import audio et analyse locale, sauvegarde locale dans l'Ondothèque, exports SVG fixes et animés.

Les fichiers audio sont analysés dans le navigateur et ne sont pas téléversés. L'Ondothèque utilise localStorage : exportez vos œuvres pour les conserver indépendamment du navigateur.
